# 📸 Folder Referencyjny Zdjęć Tomasza (Tomasz AI Reference Photos)

Ten folder został przygotowany jako baza referencyjna dla modeli generowania obrazów (np. FLUX.1, Midjourney, Imagen 3), aby tworzyć spójne grafiki przedstawiające Twoją postać w storytellingu na stronie `holisticjason.pl` oraz w social media.

## 📋 Jakie zdjęcia tutaj wgrać?
Aby uzyskać najlepsze rezultaty generowania twarzy, wgraj **5 do 10 prawdziwych zdjęć** według poniższych wytycznych:

1. **Jakość:** Wysoka rozdzielczość, ostre, dobre oświetlenie twarzy (unikaj cieni).
2. **Kąty:** Różne kąty (portret na wprost, lekki profil z lewej, lekki profil z prawej).
3. **Mimika:** Naturalna (jedno zdjęcie uśmiechnięte, jedno neutralne).
4. **Akcesoria:** Unikaj czapek, okularów przeciwsłonecznych czy szalików, które zasłaniają rysy twarzy.
5. **Format:** Pliki `.jpg` lub `.png`.

Gdy wgrasz zdjęcia, będziemy mogli użyć ich jako referencji (`Character Reference` / `Image-to-Image`) w naszych skryptach generowania grafik w agencji.
