# Implementation Notes — Holistic Jason

## Kolejność prac
1. Ustalić brand i copy.
2. Zbudować stronę usługową.
3. Ustawić strukturę contentu.
4. Dopiero potem dopinać stack i integracje API.

## Dlaczego tak
Najpierw trzeba mieć jasny system marki i sprzedaży. Dopiero później opłaca się wiązać go z narzędziami, automatyzacją i infrastrukturą.

## Co można integrować przez API
- lead capture,
- CRM,
- email automation,
- dashboard,
- knowledge base,
- content ops,
- task routing,
- analytics.

## Co trzymać w core systemie
- oferta,
- copy,
- logika sprzedaży,
- architektura informacji,
- content strategy,
- procesy decyzyjne.

## Rekomendacja
Skup się najpierw na warstwie systemowej Holistic Jason, a potem podłączaj przez API tylko to, czego faktycznie brakuje.
