## Gotowe Prompty do Tworzenia Nowego Produktu

Poniższe prompty można skopiować i użyć bezpośrednio z ChatGPt, zastępując `[branża/nisza]` oraz inne placeholders odpowiednimi informacjami.

*   **Prompty do tworzenia treści i stron sprzedażowych:**
    ```
    Stwórz przekonującą stronę sprzedażową, która podkreśla korzyści mojego kursu online w branży [branża/nisza] i przyciąga uwagę mojej grupy docelowej.
    ```
    ```
    Wymyśl listę potencjalnych tematów do mojego e-booka w branży [branża/nisza], który dostarcza wartościowych informacji i rozwiązuje problem moich czytelników.
    ```
    ```
    Napisz skrypt do wideo sprzedażowego, który skutecznie komunikuje wartość mojego produktu lub usługi w branży [branża/nisza] i motywuje widzów do działania.
    ```
    ```
    Stwórz angażujące tematy e-maili, które przyciągną uwagę moich subskrybentów i promują mój produkt online w branży [branża/nisza].
    ```
    ```
    Opracuj listę tematów webinarów, które edukują i bawią moją publiczność w branży [branża/nisza], jednocześnie pozycjonując mnie jako eksperta.
    ```
    ```
    Stwórz listę inspirujących historii sukcesu lub case studies, które mogę wykorzystać w swoim produkcie online, aby budować zaufanie.
    ```
    ```
    Stwórz listę potencjalnych pytań i odpowiedzi do sekcji FAQ dla nowego produktu w branży [branża/nisza], aby rozwiać wątpliwości klientów.
    ```

*   **Prompty do rozwoju produktu i ofert:**
    ```
    Przygotuj listę możliwości upsellu, które uzupełnią mój kurs online w branży [branża/nisza] i dodadzą jeszcze więcej wartości dla moich klientów.
    ```
    ```
    Zainspiruj mnie, tworząc listę wskazówek do opracowywania skutecznych produktów online w branży [branża/nisza], które spełniają potrzeby mojej grupy docelowej.
    ```
    ```
    Zbadaj najnowsze oprogramowanie i narzędzia, które ułatwiają tworzenie produktów online w branży [branża/nisza] i sprawiają, że proces jest bardziej efektywny.
    ```
    ```
    Zoptymalizuj moje treści, tworząc listę sposobów na przekształcanie materiałów z branży [branża/nisza] w różne formaty, takie jak posty na blogu, e-booki i webinary.
    ```
    ```
    Wymyśl listę pomysłów na stronę członkowską, które zapewniają ciągłą wartość mojej publiczności w branży [branża/nisza] i zwiększają moje źródła dochodu.
    ```
    ```
    Wymyśl listę pomysłów na kurs online w branży [branża/nisza], który rozwiązuje konkretne problemy mojej grupy docelowej i dostarcza praktycznych rozwiązań.
    ```
    ```
    Stwórz szczegółowy plan na 5-dniowe wyzwanie online w branży [branża/nisza], które buduje zaangażowanie i prowadzi do sprzedaży mojego produktu.
    ```
    ```
    Podaj listę przykładów skutecznych produktów cyfrowych w branży [branża/nisza], które mogę dostosować do potrzeb mojej publiczności.
    ```
    ```
    Przygotuj listę pomysłów na dodatkowe moduły lub bonusy, które mogę dodać do mojego kursu online w branży [branża/nisza], aby zwiększyć jego wartość.
    ```
    ```
    Podaj 10 pomysłów na produkty subskrypcyjne w branży [branża/nisza], które generują stały miesięczny dochód.
    ```
    ```
    Opracuj listę potencjalnych niszowych tematów, które mogę wykorzystać do stworzenia ekskluzywnego e-booka dla mojej publiczności.
    ```
    ```
    Stwórz listę sposobów na przekształcenie mojego kursu online w ofertę high-ticket, która przyciągnie bardziej zaangażowanych klientów.
    ```
    ```
    Wymyśl plan na stworzenie zestawu narzędzi lub zasobów w branży [branża/nisza], które będą pomocne dla moich klientów i zwiększą sprzedaż.
    ```
    ```
    Stwórz listę kreatywnych pomysłów na pakiety produktów w branży [branża/nisza], które zwiększą wartość oferty i przyciągną klientów.
    ```
    ```
    Przygotuj schemat dla mini-kursu wideo w branży [branża/nisza], który mogę stworzyć w mniej niż tydzień, aby szybko wprowadzić go na rynek.
    ```
    ```
    Pomóż mi opanować sztukę tworzenia udanych stron członkowskich w branży [branża/nisza], tworząc listę wskazówek zapewniających wysokie wskaźniki retencji i satysfakcji członków.
    ```
    ```
    Pomóż mi zwiększyć postrzeganą wartość moich produktów online w branży [branża/nisza], tworząc poczucie niedostępności, które motywuje potencjalnych klientów do szybkich działań.
    ```

*   **Prompty do monetyzacji i promocji:**
    ```
    Zaproponuj różnorodne strategie monetyzacji dla mojego bloga lub strony internetowej w branży [branża/nisza], które generują dochody pasywne.
    ```
    ```
    Zidentyfikuj listę produktów partnerskich, które są zgodne z moją publicznością w branży [branża/nisza] i oferują atrakcyjne prowizje.
    ```
    ```
    Zaproponuj strategie cenowe dla nowego produktu w branży [branża/nisza], które zwiększą jego atrakcyjność i sprzedaż.
    ```
    ```
    Odkryj najlepsze programy partnerskie dla produktów online w branży [branża/nisza].
    ```
    ```

    ```
    ```
    Przyciągnij uwagę mojej grupy docelowej, tworząc listę potencjalnych lead magnetów, które oferują wartościowe informacje i zachęcają subskrybentów.
    ```
    ```
    Stwórz skuteczne kampanie e-mailowe dla branży [branża/nisza], tworząc listę wskazówek, które angażują moich subskrybentów i zwiększają konwersje.

    ```
    Podaj pomysły na zestaw darmowych materiałów do pobrania, które pomogą promować nowy produkt online w branży [branża/nisza].
