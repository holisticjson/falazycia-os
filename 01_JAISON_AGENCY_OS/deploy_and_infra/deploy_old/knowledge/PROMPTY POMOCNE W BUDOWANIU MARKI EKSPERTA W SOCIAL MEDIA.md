### Gotowe Prompty / Szablony do ChatGPT dla Budowania Marki Osobistej w Social Media

Poniżej przedstawiono zdestylowaną listę promptów, które można wykorzystać w ChatGPT do wspierania budowania marki osobistej.

*   **Definiowanie Propozycji Wartości**
    ```
    Stwórz listę 10 kluczowych pytań, które pomogą mi zdefiniować moją unikalną propozycję wartości jako przedsiębiorcy.
    ```

*   **Plan Wyzwania w Social Media**
    ```
    Napisz plan na 5-dniowe wyzwanie w mediach społecznościowych, które pomoże wzmocnić moją markę osobistą.
    ```

*   **Pomysły na Angażujące Posty**
    ```
    Wygeneruj listę pomysłów na angażujące posty przedstawiające moje wartości i misję jako przedsiębiorcy.
    ```

*   **Definiowanie Grupy Docelowej**
    ```
    Stwórz przewodnik krok po kroku, jak określić i precyzyjnie zdefiniować moją grupę docelową.
    ```

*   **Wskazówki Dotyczące Storytellingu**
    ```
    Przygotuj zestaw wskazówek, jak opowiadać moją historię w sposób autentyczny i inspirujący dla odbiorców online.
    ```

*   **Strategie Wizualne na Instagramie**
    ```
    Opracuj listę strategii wizualnych, które pomogą mojej marce osobistej wyróżnić się na Instagramie.
    ```

*   **Elementy Strony „O mnie”**
    ```
    Stwórz listę kluczowych elementów do zamieszczenia na stronie „O mnie,” aby zwiększyć zaufanie i zaangażowanie klientów.
    ```

*   **Tematy na Wpisy Blogowe (Ekspert)**
    ```
    Przygotuj tematy na wpisy blogowe, które pozycjonują mnie jako eksperta w mojej branży.
    ```

*   **Budowanie Wizerunku na LinkedIn**
    ```
    Napisz listę sugestii, jak budować profesjonalny wizerunek marki osobistej na LinkedIn.
    ```

*   **Strategie Storytellingu dla Marki Osobistej**
    ```
    Wymyśl strategie, jak skutecznie wykorzystywać storytelling w budowaniu mojej marki osobistej.
    ```

*   **Harmonogram Publikacji Treści**
    ```
    Stwórz harmonogram publikacji treści, który pozwoli mi budować konsekwentny wizerunek online.
    ```

*   **Pomysły na Krótkie Filmy Wideo (Autentyczność, Wiedza)**
    ```
    Przygotuj listę pomysłów na krótkie filmy wideo, które podkreślą moją autentyczność i wiedzę w mojej branży.
    ```

*   **Przykłady Hashtagów do Social Media**
    ```
    Wygeneruj przykłady hasztagów, które pomogą zwiększyć widoczność mojej marki osobistej w mediach społecznościowych.
    ```

*   **Plan Działań Networkingowych Online**
    ```
    Opracuj plan działań networkingowych online, które pomogą mi nawiązać relacje z innymi liderami branży.
    ```

*   **Metody Zarządzania Reputacją Online**
    ```
    Stwórz listę skutecznych metod zarządzania reputacją online mojej marki osobistej.
    ```

*   **Pomysły na Treści Edukacyjne (Przyciąganie Grupy Docelowej)**
    ```
    Podaj pomysły na treści edukacyjne, które przyciągną moją grupę docelową i wzmocnią moją markę osobistą.
    ```

*   **Najczęściej Popełniane Błędy i Jak Ich Unikać**
    ```
    Wygeneruj listę najczęściej popełnianych błędów w budowaniu marki osobistej i jak ich uniknąć.
    ```

*   **Scenariusz na Webinar (Lider Niszy)**
    ```
    Napisz scenariusz na webinar, który pomoże mi przedstawić siebie jako lidera w mojej niszy.
    ```

*   **Wskazówki do Tworzenia Bio w Social Media**
    ```
    Stwórz zestaw wskazówek, jak zbudować autentyczny i angażujący bio na platformach społecznościowych.
    ```

*   **Strategie Promocji (Partnerstwa z Influencerami)**
    ```
    Przygotuj strategie promocji mojej marki osobistej za pomocą partnerstw z influencerami lub innymi przedsiębiorcami.
    ```

*   **Pomysły na Treści Edukacyjne (Posty, Wiedza w Branży)**
    ```
    Stwórz listę pomysłów na treści edukacyjne w formie postów, które podkreślą moją wiedzę i doświadczenie w [branża/temat].
    ```

*   **Strategia Regularnych Postów („Porada dnia” / „Tip tygodnia”)**
    ```
    Przygotuj strategię na regularne publikowanie serii postów typu „Porada dnia” lub „Tip tygodnia,” które budują mój autorytet w mojej niszy.
    ```

*   **Plan na Cykl Q&A w Social Media**
    ```
    Napisz plan na cykl Q&A w mediach społecznościowych, który pozwoli mi odpowiedzieć na pytania moich odbiorców i pokazać moją ekspertyzę.
    ```

*   **Pomysły na Krótkie Case Studies (Posty/Wideo)**
    ```
    Wymyśl pomysły na krótkie case studies w formie postów lub wideo, które zaprezentują, jak moje usługi rozwiązały konkretne problemy klientów.
    ```

*   **Zestaw Tematów na Posty/Relacje (Trendy w Branży)**
    ```
    Opracuj zestaw tematów na posty lub relacje, które przedstawiają najnowsze trendy w mojej branży i moje eksperckie spojrzenie na nie.
    ```

*   **Pomysły na Posty „Za Kulisami”**
    ```
    Stwórz listę pomysłów na posty „za kulisami,” które pokażą, jak pracuję nad rozwojem mojego biznesu, podkreślając moje profesjonalne podejście.
    ```

*   **Plan na Serię Wideo „Mit vs. Rzeczywistość”**
    ```
    Przygotuj plan na serię wideo w stylu „mit vs. rzeczywistość,” które rozwieją błędne przekonania w mojej branży i wzmocnią mój autorytet.
    ```

*   **Scenariusz na Relację/Wideo „Mój Dzień jako Ekspert”**
    ```
    Napisz scenariusz na relację lub wideo „Mój dzień jako ekspert w [branża],” aby przyciągnąć uwagę odbiorców i zbudować wiarygodność.
    ```
