### Prompty ChatGPT dla SEO Strony WWW & Pozycjonowania

Poniżej przedstawiono zdestylowaną wiedzę z pliku szkoleniowego, zawierającą gotowe do użycia prompty i schematy, pogrupowane tematycznie dla lepszej organizacji.

---

### **1. Optymalizacja Treści (Content SEO)**

*   **Pomysły na Evergreen Content:**
    ```
    Stwórz listę potencjalnych pomysłów na evergreen content dla mojej strony internetowej na temat [temat].
    ```
*   **Nagłówki H1:**
    ```
    Napisz tag H1, który dokładnie opisuje treść mojego wpisu na blogu na temat [temat].
    ```
*   **Długie Frazy Kluczowe (Long-tail keywords):**
    ```
    Wygeneruj listę długich fraz kluczowych (long-tail keywords) związanych z [temat], aby trafić do niszowych odbiorców i poprawić pozycjonowanie mojej witryny w wyszukiwarkach.
    ```
*   **Metaopisy:**
    ```
    Stwórz metaopis, który dokładnie podsumowuje treść mojej strony na temat [temat] i zachęca użytkowników do kliknięcia.
    ```
*   **Pomysły na Wpisy Blogowe:**
    ```
    Podaj listę potencjalnych pomysłów na wpisy na blogu na temat [temat], aby utrzymać zaangażowanie odbiorców i przyciągnąć nowych odwiedzających.
    ```
*   **Popularne Frazy Kluczowe:**
    ```
    Przygotuj listę popularnych fraz kluczowych o wysokim potencjale w branży [temat].
    ```
*   **Pytania typu FAQ:**
    ```
    Podaj listę pytań typu FAQ, które warto dodać na stronę na temat [temat], aby poprawić widoczność w wynikach wyszukiwania.
    ```
*   **Nagłówki H2 i H3:**
    ```
    Napisz treść nagłówków H2 i H3 do wpisu blogowego na temat [temat], które wzmocnią jego pozycjonowanie.
    ```
*   **Serie Wpisów Blogowych:**
    ```
    Wygeneruj listę potencjalnych tematów na serie wpisów blogowych, które wspólnie wzmocnią strategię SEO.
    ```
*   **Plan Publikacji Treści Sezonowych:**
    ```
    Przygotuj plan publikacji treści sezonowych na temat [temat], które mogą przyciągnąć użytkowników w określonych okresach roku.
    ```
*   **Pomysły na Interaktywne Elementy:**
    ```
    Podaj pomysły na elementy interaktywne, takie jak quizy lub kalkulatory, które mogą wzmocnić SEO witryny na temat [temat].
    ```
*   **Pomysły na Treści Edukacyjne (Ebooki/PDF):**
    ```
    Podaj pomysły na treści edukacyjne w formie ebooków lub PDF, które przyciągną ruch na stronę na temat [temat].
    ```
*   **Frazy Kluczowe w Pytaniach (Q&A):**
    ```
    Wygeneruj listę potencjalnych fraz kluczowych w pytaniach, które ludzie mogą zadawać na temat [temat].
    ```
*   **Słowa Kluczowe LSI (Latent Semantic Indexing):**
    ```
    Wygeneruj listę słów kluczowych LSI (Latent Semantic Indexing) związanych z [temat], które wzmocnią strategię treści.
    ```

### **2. Optymalizacja On-Page**

*   **Ogólne Techniki Optymalizacji On-Page:**
    ```
    Stwórz listę technik optymalizacji on-page, aby upewnić się, że każda strona na mojej witrynie jest zoptymalizowana pod kątem wyszukiwarek.
    ```
    ```
    Stwórz listę technik optymalizacji on-page, aby każda strona na mojej witrynie była zoptymalizowana zarówno dla wyszukiwarek, jak i użytkowników.
    ```
*   **Opis Alternatywny (Alt Text) dla Obrazów:**
    ```
    Stwórz opis alternatywny (alt text) dla obrazu na stronie internetowej związanej z [temat].
    ```

### **3. Optymalizacja Techniczna**

*   **Schema Markup dla Firmy Lokalnej:**
    ```
    Przygotuj prosty skrypt z kodem schema markup dla lokalnej firmy, który pomoże jej lepiej wyróżnić się w wyszukiwarce i zwiększyć widoczność online.
    ```
*   **Szybkość Ładowania Strony:**
    ```
    Wypisz sposoby na zwiększenie prędkości ładowania mojej strony, co może pozytywnie wpłynąć na doświadczenia użytkowników i pozycję w wyszukiwarkach.
    ```
*   **Schema Markup dla Artykułu Blogowego:**
    ```
    Napisz skrypt z kodem schema markup dla artykułu blogowego, aby zwiększyć widoczność w wyszukiwarce Google.
    ```
*   **Praktyki Techniczne SEO dla Indeksowania:**
    ```
    Podaj listę praktyk technicznych SEO, które mogą poprawić indeksowanie mojej witryny przez wyszukiwarki.
    ```
