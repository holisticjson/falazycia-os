### Gotowe schematy, prompty lub szablony

Poniżej przedstawiono gotowe prompty do wykorzystania w marketingu online:

*   **Prompty ogólne i dotyczące mediów społecznościowych:**
    *   ```
        Stwórz mocny nagłówek do kampanii reklamowej na Facebooku promującej [produkt/usługa].
        ```
    *   ```
        Opracuj zoptymalizowaną strategię targetowania reklam na Facebooku skierowaną do [grupa docelowa].
        ```
    *   ```
        Napisz skrypt do 30-sekundowej reklamy wideo promującej [produkt/usługa].
        ```
    *   ```
        Napisz skrypt do 60-sekundowego wideo na Instagramie promującego [temat].
        ```
    *   ```
        Przygotuj kompleksową listę platform reklamowych online, które mogę wykorzystać do promocji mojej firmy/produktów.
        ```
    *   ```
        Wygeneruj listę możliwych partnerstw w ramach marketingu influencerów dla marki [produkt/usługa].
        ```
    *   ```
        Opracuj treść e-maila zachęcającego do udziału w konkursie organizowanym przez moją firmę w branży [branża/nisza], aby zwiększyć zaangażowanie odbiorców.
        ```

*   **Prompty dotyczące stron internetowych i SEO:**
    *   ```
        Stwórz stronę docelową, aby generować leady dla [produkt/usługa].
        ```
    *   ```
        Opracuj listę kreatywnych strategii retargetingu dla strony internetowej [produkt/usługa].
        ```
    *   ```
        Stwórz przekonującą stronę sprzedażową dla [produkt/usługa].
        ```

*   **Prompty dotyczące mierzenia sukcesu:**
    *   ```
        Stwórz listę wskaźników i KPI, aby mierzyć sukces moich działań marketingu online.
        ```

*   **Prompty dotyczące e-mail marketingu:**
    *   ```
        Przygotuj listę potencjalnych kampanii e-mail marketingowych dla marki [produkt/usługa].
        ```
    *   ```
        Napisz temat e-maila, który zaangażuje subskrybentów i zachęci do otwarcia wiadomości na temat [temat].
        ```
    *   ```
        Stwórz listę angażujących kampanii e-mailowych dla [produkt/usługa].
        ```
    *   ```
        Przygotuj listę potencjalnych możliwości marketingu afiliacyjnego dla marki [produkt/usługa].
        ```
    *   ```
        Stwórz intrygujący temat e-maila, który przyciągnie uwagę mojej grupy docelowej w branży [branża/nisza] i zachęci do otwarcia wiadomości.
        ```
    *   ```
        Napisz szablon e-maila do porzuconych koszyków, aby odzyskać utracone sprzedaże w moim sklepie e-commerce [branża/nisza].
        ```
    *   ```
        Zidentyfikuj skuteczne strategie segmentacji e-maili, aby dotrzeć do mojej grupy docelowej w branży [branża/nisza] i zwiększyć współczynniki konwersji.
        ```
    *   ```
        Napisz przekonujący skrypt e-maila do kampanii nurturującej, skierowanej na pozyskanie nowych leadów w branży [branża/nisza].
        ```
    *   ```
        Zbadaj możliwości kampanii e-mailowych dla mojej firmy SaaS w branży [branża/nisza], aby zwiększyć zaangażowanie klientów.
        ```
    *   ```
        Stwórz serię automatycznych e-maili, które poprawią komunikację mojej firmy w branży [branża/nisza].
        ```
    *   ```
        Przywitaj nowych subskrybentów w branży [branża/nisza] ciepłym i angażującym skryptem e-mailowym powitalnym.
        ```
    *   ```
        Wymyśl tematy e-maili, które przyciągną uwagę subskrybentów mojego newslettera w branży [branża/nisza].
        ```
    *   ```
        Popraw skuteczność e-maili mojej firmy w branży [branża/nisza] poprzez zwiększenie wskaźników otwarć za pomocą konkretnych strategii.
        ```
    *   ```
        Ponownie zaangażuj nieaktywnych subskrybentów ożywczym skryptem e-maila re-engagement.
        ```
    *   ```
        Eksperymentuj z różnymi kampaniami e-mailowymi poprzez testy A/B, aby określić najlepsze podejście dla mojej firmy w branży [branża/nisza].
        ```
    *   ```
        E-maile wyzwalane są potężnym sposobem na zwiększenie zaangażowania klientów i konwersji. Zbadaj potencjał takiej komunikacji dla mojej firmy w branży [branża/nisza].
        ```
    *   ```
        Podziękuj klientom za zakupy w mojej firmie w branży [branża/nisza] za pomocą e-maila po zakupie, który wzmacnia relację.
        ```
    *   ```
        Zaplanuj skuteczne kampanie e-mailowe promujące wydarzenia mojej firmy w branży [branża/nisza] i zwiększające frekwencję.
        ```
    *   ```
        Upewnij się, że e-maile mojej firmy w branży [branża/nisza] docierają do skrzynek odbiorczych, wdrażając metody poprawiające dostarczalność.
        ```
    *   ```
        Zachęć do poleceń mojej firmy w branży [branża/nisza] za pomocą starannie opracowanego skryptu e-maila referencyjnego.
        ```
    *   ```
        Zyskaj cenne informacje na temat satysfakcji klientów mojej firmy w branży [branża/nisza] dzięki skryptowi e-maila z ankietą.
        ```
    *   ```
        Stwórz szablon e-maila upsellingowego, który zachęci klientów do zakupu produktów komplementarnych w branży [branża/nisza].
        ```
    *   ```
        Napisz sekwencję 3 e-maili promujących limitowaną ofertę na produkt/usługę w branży [branża/nisza].
        ```
    *   ```
        Wymyśl angażujące wezwanie do działania (CTA) w e-mailu promującym zapis na bezpłatny webinar dotyczący [temat].
        ```
    *   ```
        Przygotuj scenariusz dla kampanii drip e-mailowej, która edukuje nowych subskrybentów na temat [temat].
        ```
    *   ```
        Stwórz treść e-maila, który podkreśla kluczowe zalety mojego produktu/usługi i przekonuje do zakupu w branży [branża/nisza].
        ```
    *   ```
        Napisz szablon e-maila przypominającego o zbliżającym się terminie ważności promocji lub wydarzenia w branży [branża/nisza].
        ```
    *   ```
        Przygotuj listę pomysłów na personalizowane e-maile urodzinowe dla klientów, które wzmacniają lojalność w branży [branża/nisza].
        ```
    *   ```
        Stwórz e-mail zapraszający klientów do zapisania się na listę VIP, oferując ekskluzywne oferty i treści w branży [branża/nisza].
        ```
    *   ```
        Napisz skrypt e-maila przedstawiającego nową linię produktów/usług, która odpowiada na potrzeby grupy docelowej w branży [branża/nisza].
        ```
