### Prompty do Tworzenia Contentu na Social Media

Poniżej przedstawiono gotowe do użycia prompty i szablony, które można wykorzystać do generowania treści na platformy społecznościowe.

#### Gotowe prompty i szablony

*   **Prompty ogólne:**

    ```
    Stwórz post, który prezentuje najnowszą i najbardziej innowacyjną funkcję mojego produktu lub usługi.
    ```

    ```
    Napisz post, który dzieli się wzruszającą historią sukcesu jednego z moich zadowolonych klientów.
    ```

    ```
    Skomponuj post, który edukuje moich obserwujących o zawiłościach mojej branży i dostarcza cennych wskazówek.
    ```

    ```
    Stwórz post, który wizualnie przedstawia praktyczne zastosowanie mojego produktu lub usługi.
    ```

    ```
    Daj moim obserwującym ekskluzywne spojrzenie za kulisy mojej firmy lub branży w inspirującym poście.
    ```

    ```
    Wygeneruj post, który podkreśla moją obecność i udział w niedawnym wydarzeniu lub konferencji branżowej.
    ```

    ```
    Napisz post, który zaprasza moich obserwujących do udziału w dyskusji na temat aktualnych wydarzeń związanych z moją branżą.
    ```

    ```
    Przygotuj post, który dzieli się ciekawymi statystykami i danymi o mojej branży, aby edukować i angażować moich obserwujących.
    ```

    ```
    Podkreśl aktualną promocję lub wyprzedaż postem, który zachęca moich obserwujących do skorzystania z okazji.
    ```

    ```
    Zaproś obserwujących do podzielenia się swoją kreatywnością i pasją poprzez post z treścią wygenerowaną przez użytkowników.
    ```

    ```
    Stwórz post, który podkreśla zaangażowanie mojej firmy w działania na rzecz zrównoważonego rozwoju i ochrony środowiska.
    ```

    ```
    Napisz post, który przedstawia sesję Q&A z ekspertem w mojej branży.
    ```

    ```
    Udostępnij post, który pokazuje unikalne aspekty kultury i wartości mojej firmy.
    ```

    ```
    Skomponuj post, który prezentuje różnorodne sposoby wykorzystania mojego produktu lub usługi i jego wszechstronność.
    ```

    ```
    Napisz post, który podkreśla specjalne momenty i kamienie milowe w historii i drodze mojej firmy.
    ```

    ```
    Stwórz post typu „Przed i Po,” prezentujący efekty użytkowania mojego produktu/usługi.
    ```

    ```
    Wygeneruj post w formie quizu lub ankiety, który zaangażuje moich obserwujących i jednocześnie edukuje o mojej branży.
    ```

    ```
    Napisz post, który przedstawia historię powstania mojej firmy i inspiracje, które za nią stoją.
    ```

    ```
    Stwórz post promujący darmowy materiał, jak lead magnet, który może przyciągnąć nowych obserwujących.
    ```

    ```
    Przygotuj post z serią wskazówek lub „hacków” związanych z moją branżą, które pokazują, że jesteś ekspertem.
    ```

    ```
    Napisz post przedstawiający dzień z życia mojego zespołu, aby pokazać ludzką stronę mojej marki.
    ```

    ```
    Stwórz post w formie „Wyzwania 7-dniowego,” które zaprasza moją społeczność do działania z moim produktem.
    ```

    ```
    Przygotuj post podsumowujący najważniejsze trendy w branży i jak mój produkt wpisuje się w te zmiany.
    ```

    ```
    Napisz post, który przedstawia opinie i cytaty od moich zadowolonych klientów w formie wizualnych karuzel.
    ```

    ```
    Stwórz post, który odpowiada na najczęściej zadawane pytania o mój produkt/usługę w ciekawy i przystępny sposób.
    ```

    ```
    Przygotuj post, który inspiruje do działania, np. „Jak zacząć...” lub „Pierwszy krok do...," z wykorzystaniem mojego produktu.
    ```

    ```
    Napisz post w formie listy kontrolnej („checklist”), którą moi obserwujący mogą wykorzystać w swojej pracy lub codziennym życiu.
    ```

    ```
    Stwórz post w formie krótkiej historii sukcesu klienta, który osiągnął wyjątkowe rezultaty dzięki mojemu produktowi/usłudze.
    ```

    ```
    Przygotuj post edukacyjny, który rozwiewa popularne mity związane z moją branżą lub produktem.
    ```

    ```
    Napisz post z podziękowaniem dla klientów lub społeczności, który wzmacnia relację z moimi obserwującymi.
    ```

    ```
    Stwórz post prezentujący moje ulubione narzędzia lub aplikacje związane z moją branżą i zachęcający do ich wypróbowania.
    ```

    ```
    Przygotuj post z prognozami i przewidywaniami dotyczącymi przyszłości mojej branży, pokazując, że jestem na bieżąco z trendami.
    ```

    ```
    Napisz post w formie rekomendacji książek, podcastów lub innych zasobów edukacyjnych, które są związane z moją branżą.
    ```

    ```
    Stwórz post, który zaprasza moich obserwujących do zadawania pytań, aby lepiej zrozumieć ich potrzeby i wyzwania.
    ```

    ```
    Przygotuj post promujący współpracę lub partnerstwo z inną marką lub ekspertem w mojej branży.
    ```

    ```
    Napisz post, który zachęca moich obserwujących do podzielenia się swoimi historiami lub doświadczeniami związanymi z moją branżą.
    ```

    ```
    Stwórz post, który prezentuje „kulisy tworzenia” nowego produktu lub usługi, budując napięcie przed premierą.
    ```

*   **Prompty z wypełnianiem danych:**

    ```
    Stwórz post, który przedstawia „5 błędów do uniknięcia" w branży [branża] i jak mój produkt/usługa pomaga je rozwiązać [wpisz nazwę produktu i jego cechy].
    ```

*   **Prompty generujące instrukcje "Krok po Kroku":**

    ```
    Napisz post w formie przewodnika krok po kroku, jak osiągnąć konkretny cel przy użyciu mojego produktu/usługi.
    ```

*   **Prompty porównawcze:**

    ```
    Przygotuj post, który porównuje moją ofertę do konkurencji, podkreślając unikalne cechy i korzyści.
    ```
