## Zdestylowana Wiedza ze Skryptów Biznesowych/Marketingowych

### 1. Główne Zasady / Ramy Logiczne (Frameworki)

*   **Tekst promujący wydarzenie:** Teksty powinny budować zaangażowanie z czasem, ale unikać powtarzalności.
*   **Tekst świąteczny:** Użyj odpowiednich emotikonów.
*   **Tekst do cytatów motywacyjnych:** Użyj odpowiednich emotikonów.
*   **Ankiety i pytania:** Każda ankieta powinna mieć 2-4 odpowiedzi.

### 2. Gotowe Schematy / Prompty / Szablony

#### 1. Inspirujący tekst do zdjęcia
```
Stwórz motywujący tekst do zdjęcia [opis zdjęcia], zachęcając obserwujących do [pozytywna emocja lub działanie]. Przygotuj [X] wariantów, a każdy z nich powinien mieć maksymalnie [XX] słów.
```

#### 2. Tekst do premiery produktu
```
Napisz angażujący tekst do premiery nowego [produkt], podkreślając jego cechy i korzyści w sposób, który przyciągnie uwagę [grupa docelowa]. Przygotuj [X] wariantów, każdy maksymalnie [XX] słów.
```

#### 3. Tekst promujący wydarzenie
```
Wciel się w doświadczonego promotora wydarzeń. Stwórz serię angażujących tekstów do ogłoszenia [rodzaj wydarzenia], podkreślając [kluczowe korzyści]. Teksty powinny budować zaangażowanie z czasem, ale unikać powtarzalności. Każdy z nich maksymalnie [XX] słów.
```

#### 4. Tekst zza kulis
```
Jako doświadczony marketer social media napisz zabawny i informacyjny tekst do zdjęcia zza kulis, pokazującego przygotowania zespołu do [nazwa wydarzenia], podkreślając [kluczowe cechy/emocje]. Przygotuj [X] wariantów, każdy maksymalnie [XX] słów.
```

#### 5. Tekst świąteczny
```
Stwórz [emocjonalny] tekst na post świąteczny, życząc obserwującym radosnego [szczegóły] i podkreślając [kluczowe przesłanie]. Przygotuj [X] wariantów, każdy maksymalnie [XX] słów. Użyj odpowiednich emotikonów.
```

#### 6. Tekst do cytatów motywacyjnych
```
Przygotuj [X] inspirujących tekstów do postów z motywującymi cytatami [autor/speaker], zachęcającymi obserwujących do [działanie]. Każdy tekst nie więcej niż [XX] słów. Użyj odpowiednich emotikonów.
```

#### 7. Tekst do treści stworzonej przez użytkownika
```
Stwórz tekst do zdjęcia przesłanego przez fana, używającego [produkt], dziękując za wsparcie i zachęcając innych do udostępniania swoich zdjęć. Oznacz użytkownika. Przygotuj [X] wariantów, każdy maksymalnie [XX] słów.
```

#### 8. Tekst promocyjny sezonowy
```
Napisz chwytliwy tekst na post promujący wyprzedaż [sezon] dla [firma], podkreślając [główna promocja/korzyść] i zapraszając obserwujących do skorzystania z oferty ograniczonej czasowo, kończącej się [data]. Przygotuj [X] wariantów, każdy maksymalnie [XX] słów.
```

#### 9. Tekst angażujący społeczność
```
Stwórz tekst do postu, zachęcający obserwujących do podzielenia się [pomysłem/rekomendacją] dotyczącym [wydarzenia, tematu]. Przygotuj [X] wariantów, każdy maksymalnie [XX] słów.
```

#### 10. Eksperckie wskazówki
```
Jesteś ekspertem w dziedzinie [branża]. Wypisz [X] krótkich, praktycznych wskazówek dotyczących [temat], które pomogą odbiorcom [osiągnąć cel]. Każda wskazówka nie więcej niż [XX] słów.
```

#### 11. Ankiety i pytania
```
Jesteś ekspertem w online marketingu. Stwórz prostą ankietę dotyczącą [produkt/pomysł], zachęcając obserwujących do podzielenia się opinią. Przygotuj [X] wariantów pytań. Każda ankieta powinna mieć 2-4 odpowiedzi.
```

#### 12. Zapowiedź nadchodzącego produktu
```
Stwórz tekst zapowiadający [nadchodzący produkt lub wydarzenie] z ciekawymi szczegółami, które zbudują oczekiwanie wśród [grupa docelowa]. Przygotuj [X] różnych wariantów, każdy maksymalnie [XX] słów.
```

#### 13. Konkursy, wyzwania i rozdania
```
Stwórz teksty do postów ogłaszających konkurs, w którym można wygrać [nagroda], wyjaśniając korzyści z uczestnictwa. Przygotuj [X] postów, każdy do [XX] słów.
```

#### 14. Opinie klientów
```
Stwórz serdeczny tekst do postu, w którym dzielisz się pozytywną opinią klienta na temat [produkt], z wezwaniem do innych klientów, aby podzielili się swoimi historiami. Wykorzystaj ten cytat: [cytat] i najważniejsze informacje: [szczegóły]. Tekst nie więcej niż [XX] słów.
```

#### 15. Trendy w branży
```
Jesteś ekspertem w dziedzinie [branża]. Stwórz [X] krótkich tekstów na temat obecnych trendów lub gorących tematów w [branża], oferując unikalny punkt widzenia Twojej marki. Każdy tekst nie więcej niż [XX] słów.
```

#### 16. Ciekawostki i przydatne fakty
```
Jako ekspert w [branża] stwórz [X] interesujących i mało znanych faktów związanych z [branża lub produkt]. Spraw, aby były użyteczne i istotne dla odbiorców [grupa docelowa]. Każdy fakt maksymalnie [XX] słów.
```

#### 17. Zachęta do treści tworzonej przez użytkowników
```
Stwórz [X] postów zachęcających obserwujących do dzielenia się treściami związanymi z [produkt/usługa]. Dodaj hashtag i wyjaśnij, w jaki sposób ich treści mogą zostać wyróżnione na naszym [konta/strona]. Każdy post do [XX] słów.
```
