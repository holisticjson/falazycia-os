## Prompty ChatGPT do Generowania Leadów

Poniżej przedstawiono gotowe do użycia prompty, które pomogą w procesie generowania leadów.

### Generowanie Nagłówków i Tematów

*   **Tworzenie nagłówków dla lead magnetów:**
    ```
    Stwórz chwytliwy nagłówek dla lead magnetu na temat [temat]
    ```
*   **Pisanie intrygujących tematów e-mail:**
    ```
    Napisz intrygujący temat e-maila, który zachęci odbiorców do umówienia się na niezobowiązującą konsultację
    ```
*   **Tworzenie przekonujących nagłówków dla lead magnetów:**
    ```
    Napisz przekonujący nagłówek dla lead magnetu na temat [temat]
    ```
*   **Tworzenie tematów e-mail do newslettera:**
    ```
    Napisz temat e-maila, który skłoni odbiorców do zapisania się na mój newsletter
    ```

### Projektowanie Stron i Elementów Generujących Leady

*   **Projektowanie strony docelowej do generowania leadów:**
    ```
    Zaprojektuj stronę docelową generującą leady dla [produktu/usługi]
    ```
*   **Tworzenie pop-upów generujących leady:**
    ```
    Stwórz pop-up generujący leady na mojej stronie internetowej
    ```
*   **Generowanie pop-upów z darmowymi materiałami:**
    ```
    Wygeneruj pop-up na mojej stronie internetowej oferujący bezpłatne pobranie materiałów
    ```
*   **Budowanie strony docelowej na bezpłatny okres próbny:**
    ```
    Zbuduj stronę docelową generującą leady na bezpłatny okres próbny dla [produkt/usługa]
    ```

### Pomysły na Lead Magnety

*   **Lista potencjalnych lead magnetów dla programu coachingowego:**
    ```
    Przygotuj listę potencjalnych lead magnetów dla programu coachingowego w biznesie
    ```
*   **Pomysły na lead magnet dla serwisu sprzątającego:**
    ```
    Podaj listę pomysłów na lead magnet dla serwisu sprzątającego
    ```
*   **Potencjalne lead magnety dla programu fitness:**
    ```
    Przygotuj listę potencjalnych lead magnetów dla programu fitness
    ```
*   **Pomysły na lead magnet dla serwisu remontowego:**
    ```
    Stwórz listę pomysłów na lead magnet dla serwisu remontowego
    ```

### Skrypty Reklamowe i Wezwania do Działania (CTA)

*   **Skrypt do reklamy na Facebooku (okres próbny):**
    ```
    Napisz skrypt do reklamy na Facebooku promującej bezpłatny okres próbny oprogramowania
    ```
*   **Lista wezwań do działania na stronę zapisu na webinar:**
    ```
    Stwórz listę przyciągających uwagę wezwań do działania na stronę zapisu na webinar
    ```
*   **Skrypt do reklamy na Facebooku (darmowa konsultacja):**
    ```
    Napisz skrypt do reklamy na Facebooku promującej darmową konsultację
    ```
*   **Lista perswazyjnych wezwań do działania na stronę z darmowymi zasobami:**
    ```
    Przygotuj listę perswazyjnych wezwań do działania na stronę z bezpłatnymi zasobami
    ```

### Badania i Słowa Kluczowe

*   **Pytania do ankiety generującej leady:**
    ```
    Przygotuj listę pytań do umieszczenia w ankiecie do generowania leadów
    ```
*   **Słowa kluczowe do generowania leadów (Adwords):**
    ```
    Przygotuj listę słów kluczowych związanych z [temat] do generowania leadów za pomocą Adwords
    ```
*   **Pytania do ankiety dla subskrybentów e-mailowych:**
    ```
    Stwórz listę pytań do ankiety wysyłanej do moich subskrybentów e-mailowych
    ```
*   **Słowa kluczowe do kampanii Black Friday:**
    ```
    Przygotuj listę słów kluczowych związanych z [temat], które pomogą w kampanii reklamowej Black Friday i zwiększą zapisy na moją listę mailingową
    ```
