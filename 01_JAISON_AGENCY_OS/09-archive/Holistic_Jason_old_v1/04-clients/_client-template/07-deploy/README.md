# 07-deploy — Instrukcje Wdrożeniowe i DNS

Centrum instrukcji wdrożeniowych na hosting (FTP, Cloud Run, Firebase, itp.), konfiguracji domen, rekordów DNS, certyfikatów SSL oraz konfiguracji serwerowych.

## Zawartość folderu:
- Instrukcje wdrożenia krok po kroku
- Konfiguracje rekordów DNS (A, CNAME, MX, TXT/SPF/DKIM dla poczty)
- Skrypty do deployu specyficzne dla klienta
