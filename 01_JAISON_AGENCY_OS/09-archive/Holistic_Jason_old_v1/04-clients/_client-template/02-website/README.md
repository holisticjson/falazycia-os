# 02-website — Kod Strony WWW i SEO

Katalog zawierający kod źródłowy stron internetowych, audyty techniczne SEO/AEO, backupy baz danych, konfiguracje domen oraz mapy witryn.

## Zawartość folderu:
- Pliki HTML/CSS/JS lub szablony stron
- Audyty SEO, opisy struktury Schema.org (JSON-LD)
- Konfiguracje routingu, pliki `.htaccess`, itp.
- Backupy baz danych i eksporty CMS
