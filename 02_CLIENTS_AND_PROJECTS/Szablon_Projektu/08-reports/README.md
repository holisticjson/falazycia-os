# 📁 08-reports
> **Cel:** Analityka, raportowanie wyników, ROI oraz zestawienia dla klienta.

### Co tu wrzucać?
- Raporty konwersji lejków sprzedażowych.
- Statystyki odwiedzin (Google Analytics 4, GSC).
- Podsumowania z kampanii reklamowych (ROAS, CAC, LTV).
- Comiesięczne lub cotygodniowe raporty przygotowywane bezpośrednio dla klienta.
