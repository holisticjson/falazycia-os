🚀 Szybka Inicjalizacja Projektu w 3 Krokach

Zasada zerowego oporu (Low Friction). Stosuj tę checklistę przy każdym nowym projekcie:

  • 1
    Klonowanie Szablonu
    Skopiuj folder Szablon_Projektu i nazwij go nazwą klienta w katalogu 02_CLIENTS_AND_PROJECTS.
  • 2
    Audyt 21 Pytań
    Otwórz plik 00-admin/21_questions_audit_template.md i wypełnij odpowiedzi (lub wklej wyniki z wywiadu/bota). Stanowi to fundament wiedzy dla agentów.
  • 3
    Inicjalizacja WORKSPACE_MEMORY.md
    Stwórz plik WORKSPACE_MEMORY.md w głównym folderze projektu (skopiuj go z bazy). Zdefiniuje to bieżący cel, status oraz tech stack.

⚙️ Środowisko: Local vs New Worktree (Kluczowa Decyzja)

Otwierając nową konwersację z agentem w AntiGravity, zawsze wybieraj mądrze:

Cecha 🟢 Local (Środowisko Lokalne) 🔮 New Worktree (Nowe Drzewo Robocze)
Opis działania Agent edytuje pliki bezpośrednio na Twoim dysku na żywo. Agent klonuje projekt do ukrytego folderu w tle i tam pracuje.
Wielowątkowość Niska. Uruchomienie kilku agentów w Local zniszczy kod. Nielimitowana. Możesz delegować 5 zadań na raz.
Zastosowanie Szybkie poprawki, natychmiastowe debugowanie, gdy patrzysz na kod. Duże zadania, pisanie modułów, marketing, asynchroniczna praca.
Rekomendacja Używaj rzadko, tylko do prostych edycji "tu i teraz". REKOMENDOWANE domyślnie. Czysto, bezpiecznie, bez tarć.

🤝 Protokół Sztafety Agentów

Aby agenci nie wchodzili sobie w drogę i nie nadpisywali Twojej pracy, stosuj model sztafety:

  • A
    Główna gałąź to Świętość
    Twoje główne VS Code / edytor trzymasz na gałęzi main. Nie robisz na niej eksperymentów.
  • B
    Delegowanie na boku
    Zlecasz zadanie przez New Worktree (np. gałąź website/add-contact-form).
  • C
    Automatyczny Review
    Agent kończy pracę, generuje plik walkthrough.md i zgłasza gotowość. Scalasz zmiany do main.

🐍 Kod do osadzenia w Streamlit Dashboard

Chcesz wyświetlić tę instrukcję w swoim luksusowym panelu Streamlit? Skopiuj i wklej ten prosty snippet: 

import streamlit as st
import streamlit.components.v1 as components

def render_guide():
    path = "antigravity_workflow_guide.html"
    if os.path.exists(path):
        with open(path, "r", encoding="utf-8") as f:
            html_code = f.read()
        components.html(html_code, height=800, scrolling=True)
    else:
        st.error("Brak pliku instrukcji!")
