# 📁 07-deploy
> **Cel:** Infrastruktura sieciowa, serwery, DNS, backupy oraz wdrożenia produkcyjne.

### Co tu wrzucać?
- Konfigurację rekordów DNS (np. Cloudflare).
- Instrukcje wdrażania (FTP, SSH, komendy CLI, deployment na Google Cloud / VPS).
- Skrypty i pliki konfiguracyjne (Dockerfile, docker-compose).
- Logi z wdrożeń oraz plany odzyskiwania danych (Disaster Recovery).
