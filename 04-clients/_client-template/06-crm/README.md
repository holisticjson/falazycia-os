# 06-crm — Dane Leadów i Komunikacja

Katalog dla baz danych leadów, list mailingowych, notatek ze spotkań handlowych, lejków sprzedażowych oraz segmentacji kontaktów.

- Eksporty baz danych / kontaktów (CSV)
- Notatki ze spotkań biznesowych
- Strategie segmentacji kontaktów i tagowania w Systeme.io
- Skrypty mailingowe i szablony wiadomości bezpośrednich
