# 09-archive — Archiwum Historyczne

Krypta na stare pomysły, nieaktywne podstrony, odrzucone lub przestarzałe wersje kreacji, archiwalne dokumenty oraz stare konfiguracje.

## Zawartość folderu:
- Poprzednie wersje projektów stron i grafik
- Nieużywane już kody i skrypty automatyzacji
- Nieaktualne briefy i stare raporty finansowe
