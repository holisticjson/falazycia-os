# 00-admin — Administracja i Dostęp

Miejsce na dane organizacyjne, rejestracyjne, umowy, faktury, dane dostępowe (credentials) oraz klucze API.

## Zawartość folderu:
- Pliki konfiguracji API i kluczy uwierzytelniających (np. `credentials.json`, `tokens.pickle`)
- Dane dostępowe (FTP, cPanel, CMS, Systeme.io, itp.)
- Pliki instrukcji, briefów początkowych i umów

> [!WARNING]
> Wszelkie klucze API i poufne dane logowania mogą znajdować się wyłącznie w tym podkatalogu. Kategorycznie zabrania się umieszczania haseł i tokenów w kodzie źródłowym stron.
