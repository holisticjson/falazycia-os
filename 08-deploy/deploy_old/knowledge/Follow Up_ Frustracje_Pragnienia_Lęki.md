### 1. Główne zasady / ramy logiczne (Frameworki)

*   **Framework analizy profilu klienta "Frustracje – Pragnienia – Lęki"**: Metoda rozumienia potrzeb, motywacji i obaw potencjalnych klientów w procesie sprzedaży i komunikacji.
    *   **Cel**: Dokładne zidentyfikowanie i adresowanie kluczowych problemów (frustracji), pożądanych rozwiązań (pragnień) oraz ukrytych obaw (lęków), które wpływają na decyzje klienta.
    *   **Struktura**: Analiza każdego punktu bólu klienta przez pryzmat jego bezpośredniego pragnienia i podstawowego lęku.

### 2. Gotowe schematy (analiza profilu klienta)

Poniżej przedstawiono zbiór konkretnych wzorców myślowych klientów, analizujących ich frustracje, odpowiadające im pragnienia oraz towarzyszące lęki. Mogą być one wykorzystane jako baza do tworzenia komunikatów i strategii sprzedażowych, adresując każdy z tych elementów.

```
# Frustracja: Klienci nie odpowiadają na wiadomości.
## Pragnienie: Chcą, aby klienci szybciej podejmowali decyzje zakupowe.
### Lęk: Obawa przed byciem nachalnym i zrażeniem klienta.
```

```
# Frustracja: Brak czasu na regularne follow-upy.
## Pragnienie: Marzą o automatyzacji procesu follow-up.
### Lęk: Strach przed utratą klienta przez zbyt długi czas oczekiwania na odpowiedź.
```

```
# Frustracja: Trudność w znalezieniu odpowiedniego momentu na kontakt.
## Pragnienie: Chcą lepiej rozumieć potrzeby klienta.
### Lęk: Obawa przed tym, że klient wybierze konkurencję.
```

```
# Frustracja: Klienci ignorują oferty, mimo wcześniejszego zainteresowania.
## Pragnienie: Chcą, aby ich oferty były bardziej atrakcyjne i skuteczne.
### Lęk: Lęk przed odrzuceniem lub brakiem reakcji na follow-up.
```

```
# Frustracja: Brak jasnych procedur dotyczących follow-up w firmie.
## Pragnienie: Pragną mieć gotowe schematy kontaktu z klientami.
### Lęk: Strach przed błędem w komunikacji, który zaszkodzi relacji z klientem.
```

```
# Frustracja: Zbyt duża liczba potencjalnych klientów do obsłużenia indywidualnie.
## Pragnienie: Chcą lepiej zarządzać swoim czasem i priorytetami.
### Lęk: Obawa, że nie będą w stanie odpowiednio obsłużyć wszystkich klientów.
```

```
# Frustracja: Klienci często zmieniają zdanie lub odkładają decyzję na później.
## Pragnienie: Marzą o skutecznych technikach przyspieszania decyzji zakupowych.
### Lęk: Strach przed utratą klienta przez zbyt długie oczekiwanie na decyzję.
```

```
# Frustracja: Brak odpowiednich narzędzi do śledzenia kontaktów z klientami.
## Pragnienie: Chcą korzystać z nowoczesnych narzędzi CRM, które ułatwią zarządzanie relacjami.
### Lęk: Obawa przed kosztami wdrożenia nowych technologii.
```

```
# Frustracja: Trudność w personalizacji wiadomości follow-up.
## Pragnienie: Pragną tworzyć bardziej spersonalizowaną i angażującą komunikację.
### Lęk: Lęk przed tym, że ich wiadomości będą wyglądały jak spam.
```

```
# Frustracja: Presja ze strony przełożonych na szybkie wyniki sprzedażowe.
## Pragnienie: Chcą mieć więcej czasu na budowanie relacji z klientami.
### Lęk: Strach przed nieosiągnięciem celów sprzedażowych i utratą pracy.
```
