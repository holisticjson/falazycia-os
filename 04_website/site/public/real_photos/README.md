# Folder na Twoje Zdjęcia i Certyfikaty (holisticjson.pl)

Wgraj tutaj pliki graficzne ze swojego komputera stacjonarnego, aby automatycznie pojawiły się w zasobach strony i zostały użyte w kodzie:

1.  **Zdjęcia profilowe / tła:** (np. `tomasz_real_photo.png` do wdrożenia w sekcji Hero).
2.  **Certyfikat Google (Umiejętności Jutra):** (np. `certyfikat_google.png` do sekcji autorytetu / o mnie).

### Jak ich użyć w kodzie strony?
W pliku `index.html` (lub w kreatorze) będą one dostępne pod ścieżką relatywną:
`./real_photos/nazwa_pliku.png`
